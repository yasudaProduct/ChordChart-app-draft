# 機能一覧

ChordBook アプリケーションの機能概要です。

## コンセプト

既存のコード掲載サイトの不満（広告、見づらさ、印刷品質）を解消し、オリジナル曲も含めてコード譜を一元管理できるサービス。

### 楽曲管理

**楽曲情報**

| フィールド   | 説明                         |
| ------------ | ---------------------------- |
| タイトル     | 曲名（必須）                 |
| アーティスト | アーティスト名（任意）       |
| キー         | 原曲のキー（C, Am 等・任意） |
| BPM          | テンポ（任意）               |
| 拍子         | 4/4, 3/4 等（任意）          |

タイトル以外はすべて任意項目で、未設定のまま楽曲を作成・保存できる。未設定の項目は詳細・プレビュー・共有・演奏モード・印刷のいずれでも項目ごと非表示になる（`lib/songMeta.ts`）。

キー・BPM・拍子は**セクション単位でも設定でき**、楽曲全体の値はセクションが未設定のときの既定値として働く（下記「セクション単位のキー・BPM・拍子」）。

**アーティスト名サジェスト**

- 新規作成画面・エディタのアーティスト入力欄で候補をドロップダウン表示
- 候補は公開楽曲のアーティスト名（`GET /api/songs/artists`）で、登録数の多い順
- 大文字小文字・全角半角・空白の表記ゆれを正規化して重複排除
- 候補一覧は一括取得してキャッシュし、入力中の絞り込みはクライアント側で実施
- 候補にない名前もそのまま自由入力できる

**楽曲一覧**

- 公開楽曲（`visibility = public`）を投稿者に関わらず全ユーザー分一覧表示（認証不要）
- 更新日時でソート
- 検索・フィルター（クライアント側）

**楽曲詳細**

- コード譜の表示
- メタ情報の表示
- 編集・削除

### コード譜エディター

**セクション管理**

- イントロ、Aメロ、サビ等のセクション
- セクションの追加・削除・並べ替え
- セクションごとのキー・BPM・拍子（セクションヘッダーの「♪」で開閉。設定済みなら値がバッジ表示される）

**セクション単位のキー・BPM・拍子**

転調・テンポチェンジ・変拍子を、セクション単位で表現できる。

- 未設定のセクションは**直前のセクションから引き継ぐ**（carry-forward）。それも無ければ楽曲全体の値を使う
- 引き継ぎはフィールドごとに独立（BPM だけ設定したセクションでも、キーは以前の値のまま）
- 表示は**変化した箇所にだけ**出す。転調したセクションの見出しに「Key Am · BPM 90 · 6/8」が付き、引き継ぐだけのセクションには何も出ない（紙の譜面と同じ読み味）
- 詳細・プレビュー・共有・印刷・演奏モードのすべてに反映される
- 移調するとセクションのキーも一緒に移調され、コードの ♯/♭ 綴りは各セクションのキーに合わせて決まる
- コード候補（ダイアトニック・次コード予測・代理コード）は編集中セクションの有効キーで算出される
- 演奏モードの自動スクロール速度は、表示中セクションの有効 BPM に連動する

一度設定した値を「以降は未設定に戻す」表現手段はない（空欄＝継承のため）。元の値に戻したい場合は明示的に設定し直す。

**入力モード**

| モード      | 説明                   |
| ----------- | ---------------------- |
| 歌詞+コード | 歌詞の上にコードを配置 |
| コードのみ  | 小節ごとにコードを配置 |

**歌詞+コードモード**

```
C        G        Am       F
きょうも いちにち がんばった
```

**コードのみモード**

```
| C | G | Am | F |
| C | G | F  | G |
```

**プレビュー**

- リアルタイムプレビュー
- 印刷プレビュー

### 共有機能

**公開設定**

| 設定     | 説明                   | ログインなしで閲覧      |
| -------- | ---------------------- | ----------------------- |
| 非公開   | 自分のみ               | ×                       |
| URL 共有 | URL を知っている人のみ | ○（共有リンク経由）     |
| 公開     | 全ユーザーに公開       | ○（楽曲一覧・検索から） |

**共有リンク（URL共有）**

- 一意の URL を生成（`/share/:token`）
- 有効期限の設定（オプション）
- ログインなしで閲覧可能
- 閲覧のみ（編集にはログインが必要）

### エクスポート

**印刷 / PDF（実装済み・印刷 CSS 方式）**

- A4 サイズ（`@page` 設定・余白 14mm）
- セクション途中での改ページ抑止、コードは黒太字で印刷
- ブラウザの印刷ダイアログから「PDFとして保存」で出力
- PDF ファイルの直接生成はマネタイズ検討と合わせて将来対応

---

### 演奏支援

**トランスポーズ（実装済み）**

- 閲覧画面（詳細・共有・演奏モード）: 半音単位の非破壊移調（保存されない）
- エディタ: キー変更時に「コードも移調 / キー表記のみ変更」を選択（実データを書き換え）
- セクションに設定されたキーも一緒に移調される
- 綴りは移調後のキーの調号（♯/♭）に自動で揃う。セクションごとにキーが違えば、綴りもセクションごとに決まる
- カポ位置の計算 - 将来対応

**演奏モード / 自動スクロール（実装済み）**

- フルスクリーンの演奏向け表示（ダーク背景・文字サイズ調整）
- BPM に合わせた自動スクロール + 速度調整（×0.25〜×3）
- スクロール速度は表示中セクションの有効 BPM に連動して切り替わる（コントロールバーに現在の BPM を表示）
- キーボード操作（Space: 再生/停止、↑↓: 速度、Esc: 終了）
- Wake Lock による画面消灯防止（対応ブラウザ）

**メトロノーム - 将来対応**

- BPM に合わせたクリック音
- 拍子に対応

## 画面一覧

| 画面           | パス           | 認証   | 説明                                               |
| -------------- | -------------- | ------ | -------------------------------------------------- |
| ホーム         | /              | 不要   | ランディングページ                                 |
| ログイン       | /login         | 不要   | ログイン画面                                       |
| 登録           | /register      | 不要   | ユーザー登録画面                                   |
| 楽曲一覧       | /songs         | 不要   | 全ユーザーの公開楽曲一覧（自分の楽曲に限定しない） |

| 楽曲作成       | /songs/new     | 必要   | 新規楽曲作成（公開範囲も指定可能）                 |

| 共有楽曲表示   | /share/:token  | 不要   | 共有リンクからの閲覧（移調・演奏モード対応）       |
| プロフィール   | /profile       | 必要   | ユーザー設定                                       |
| 自分の楽曲一覧 | /profile/songs | 必要   | 非公開・URL限定を含む自分の全曲一覧                |
