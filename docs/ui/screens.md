## 1. ホーム画面

**パス**: `/`
**認証**: 不要

### 概要

サービスの紹介とユーザーを招き入れるランディングページ。

### 構成要素

```
┌──────────────────────────────────────────────────┐
│ [ロゴ]                    [ログイン] [新規登録]   │ ← ヘッダー
├──────────────────────────────────────────────────┤
│                                                  │
│         ChordBook                                │
│         コード譜を、もっと自由に                   │
│                                                  │
│         [無料で始める]                            │
│                                                  │
├──────────────────────────────────────────────────┤
│  特徴1: 直感的なエディタ                          │
│  特徴2: どこでもアクセス                          │
│  特徴3: 簡単共有                                 │
├──────────────────────────────────────────────────┤
│                    フッター                       │
└──────────────────────────────────────────────────┘
```

### アクション

- 「無料で始める」→ 新規登録画面へ
- 「ログイン」→ ログイン画面へ
- ログイン済みの場合は楽曲一覧へリダイレクト

## 4. 楽曲一覧画面

**パス**: `/songs`
**認証**: 不要（公開楽曲のみ表示）

### 概要

楽曲の一覧を表示。認証の有無や投稿者に関わらず、公開設定（`visibility = public`）の楽曲を全ユーザー分表示する（自分の楽曲に限定しない）。カードには詳細リンクのみを表示し、編集・削除は楽曲詳細画面（自分の楽曲の場合のみ）で行う。

### 構成要素

```
┌──────────────────────────────────────────────────┐
│ [ロゴ]     [検索] [ブックマーク] [ユーザーメニュー]│
├──────────────────────────────────────────────────┤
│                                                  │
│  楽曲一覧                          [+ 新規作成]   │
│                                                  │
│  [検索: _______________] [並び替え: 更新日時 ▼]  │
│                                                  │
│  ┌────────────────────────────────────────────┐ │
│  │ ♪ 曲名1                                    │ │
│  │   アーティスト名 | Key: C | BPM: 120       │ │
│  │   更新: 2026/02/01                    [詳細]│ │
│  └────────────────────────────────────────────┘ │
│  ┌────────────────────────────────────────────┐ │
│  │ ♪ 曲名2                                    │ │
│  │   アーティスト名 | Key: Am | BPM: 90       │ │
│  │   更新: 2026/01/30                    [詳細]│ │
│  └────────────────────────────────────────────┘ │
│                                                  │
│  [もっと見る]                                    │
│                                                  │
└──────────────────────────────────────────────────┘
```

### 機能

- 楽曲カードの表示（タイトル、アーティスト、キー、更新日、詳細リンクのみ）
- 検索フィルター（クライアント側、タイトル・アーティストの部分一致）
- 新規作成ボタン
- 並び替え・コンテキストメニュー（複製、削除、共有）は未実装（ロードマップ G15 / E3 / E20 参照）

### アクション

- 楽曲カードクリック（詳細リンク） → 楽曲詳細画面へ
- 「+ 新規作成」→ 楽曲新規作成画面へ

## 5. 楽曲詳細画面

**パス**: `/songs/:id`
**認証**: 部分的（自分の楽曲 or 公開楽曲）

### 概要

楽曲のコード譜を閲覧する画面。譜面の表示はエディタのプレビューと共通のコンポーネント（`ChordSheet`）を使い、デザイン・印刷出力が一致する。

### 構成要素

```
┌──────────────────────────────────────────────────┐
│      [▶ 演奏モード] [編集] [印刷/PDF] [一覧へ戻る] │
│  [移調 − 0 + ]                                   │
├──────────────────────────────────────────────────┤
│  曲名タイトル                                     │
│  アーティスト名   Key: C   BPM: 120   4/4        │
│  ═══════════════════════════════════════════    │
│                                                  │
│  INTRO                                           │
│  C        G        Am       F                    │
│                                                  │
│  VERSE 1                                         │
│  C        G        Am       F                    │
│  きょうも いちにち がんばった                      │
│                                                  │
│  CHORUS  Key Am · BPM 90                         │
│  Am       F        C        G                    │
│  さあ うたおう みんなで                            │
│                                                  │
└──────────────────────────────────────────────────┘
```

曲名・アーティスト・キー等のヘッダーは譜面（`ChordSheet`）の一部として表示する。ページ上部は操作ボタンのみで、印刷時にはボタン・移調コントロールが非表示になり譜面だけが出力される。

### 機能

- コード譜の表示（エディタプレビューと同一デザイン）
- トランスポーズ（キー変更）
- PDF エクスポート / 印刷（エディタからの印刷と同一出力）
- 共有リンク生成
- ブックマーク追加（他ユーザーの楽曲の場合、未実装）
- 編集・削除ボタンは所有者本人（`isOwner`）にのみ表示。`/songs` の一覧が全ユーザーの公開楽曲になったため、編集・削除はこの詳細画面に集約している

## 7. エディタ画面

**パス**: `/editor/:id`
**認証**: 必要（かつ所有者本人のみ。`song.isOwner` が `false` の場合は編集画面へのアクセスを拒否し、一覧へ戻るリンクを表示する）

### 概要

コード譜を編集するメイン画面。PC優先設計、Notion風ブロックベースUI。`/songs` が全ユーザーの公開楽曲一覧になり ID が誰でも把握できるようになったため、フロント側でも所有者チェックを行う（保存自体はバックエンドの所有者チェックでも拒否される）。

### 全体レイアウト

```
┌───────────────────────────────────────────────────────────────────┐
│ [ロゴ] 曲名        [保存中...] [元に戻す][やり直す] [プレビュー]  │
├───────────────────────────────────────────────────────────────────┤
│                              │                                    │
│  【エディタエリア】           │   【プレビューエリア】              │
│                              │                                    │
│  ┌─ メタ情報 ──────────────┐ │   曲名タイトル                     │
│  │ 曲名: [_____________]   │ │   アーティスト名                   │
│  │ アーティスト: [______]  │ │   Key: C | BPM: 120               │
│  │ キー: [C▼] ✓自動検出   │ │   ─────────────────               │
│  │ BPM: [120] 拍子: [4/4▼]│ │                                    │
│  └─────────────────────────┘ │   [Intro]                          │
│                              │   | C | G | Am | F |               │
│  ┌─ Intro [歌詞+コード▼] ♪ ┐ │                                    │
│  │ ≡ コードレーン:         │ │   [Verse 1]                        │
│  │   [C]    [G]   [Am]  [F]│ │   C        G                       │
│  │ 歌詞行:                 │ │   きょうも いちにち                 │
│  │   (イントロのため空)     │ │                                    │
│  │        [+ 行を追加]     │ │   [Chorus] Key Am · BPM 90         │
│  └─────────────[複製][削除]┘ │   Am       F                       │
│                              │   さあ うたおう                     │
│  ┌─ Chorus [コード▼] ♪Key Am┐│                                    │
│  │ キー[Am▼] BPM[90] 拍子[▼]│ │  ← ♪ で開閉する設定行             │
│  │ ...                     │ │                                    │
│  └─────────────────────────┘ │                                    │
│                              │                                    │
│  [+ セクションを追加]         │                                    │
│                              │                                    │
├──────────────────────────────┴────────────────────────────────────┤
│ ステータス: 保存済み | 推定キー: C | コード数: 24                  │
└───────────────────────────────────────────────────────────────────┘
```

### ヘッダー部

| 要素                | 説明                                          |
| ------------------- | --------------------------------------------- |
| ロゴ                | クリックで楽曲一覧へ                          |
| 曲名表示            | 現在編集中の曲名                              |
| 保存ステータス      | 「保存済み」「保存中...」「未保存の変更あり」 |
| 元に戻す / やり直す | Undo / Redo ボタン                            |
| プレビュートグル    | プレビューエリアの表示/非表示                 |

### メタ情報セクション

| 項目         | 説明                                           |
| ------------ | ---------------------------------------------- |
| 曲名         | 必須入力                                       |
| アーティスト | 任意入力                                       |
| キー         | ドロップダウン選択（未設定可）+ 推定キーの適用 |
| BPM          | 数値入力（未設定可）                           |
| 拍子         | ドロップダウン（未設定 / 4/4, 3/4, 6/8, 2/4）  |

キー・BPM・拍子はここで曲全体の値を決める。セクションごとに違う値を持たせたい場合は、各セクションヘッダーの「♪」から設定する（下記「セクション単位のキー・BPM・拍子」）。

### セクション管理

各セクションはNotion風のブロックとして管理。

**セクションヘッダー**:

- ドラッグハンドル（≡）で並べ替え
- セクション名編集（Intro, Verse 1, Chorus 等）
- 表示形式切替（歌詞+コード / 小節形式）
- 「♪」トグル（キー・BPM・拍子の設定行を開閉。設定済みなら値をバッジ表示）
- 複製ボタン
- 削除ボタン

**セクション単位のキー・BPM・拍子**:

「♪」を押すとヘッダー直下に設定行が開く。

```
┌─ ⋮⋮ [サビ] [歌詞+コード|コード] ♪ Key Am · BPM 90   📋 ↑ ↓ 🗑 ─┐
│  キー [Am        ▼]  BPM [90    ]  拍子 [未設定（継承: 4/4）▼] │
├────────────────────────────────────────────────────────────────┤
│  [Am]      [F]      [C]      [G]                               │
│  さいごの　ワンフレーズ                                          │
└────────────────────────────────────────────────────────────────┘
```

| 項目 | 説明                                                                |
| ---- | ------------------------------------------------------------------- |
| キー | ドロップダウン。未設定の選択肢に「未設定（継承: C）」と継承値を表示 |
| BPM  | 数値入力。プレースホルダに継承値を表示                              |
| 拍子 | ドロップダウン。キーと同様に継承値を表示                            |

未設定のままにすると**直前のセクション → 楽曲全体**の順に継承される。ヘッダーのバッジには、そのセクション自身に設定した値だけが出る（継承値は出ない）。

閲覧側（詳細・共有・プレビュー・印刷・演奏モード）のセクション見出しには、**直前のセクションから変化した項目だけ**が「Key Am · BPM 90 · 6/8」の形で付く。引き継ぐだけのセクションには何も出ない。

**歌詞+コード形式**:

```
┌────────────────────────────────────────────────┐
│ コードレーン:  [C]      [G]      [Am]     [F]  │  ← コードチップ（ドラッグ移動可）
│ 歌詞行:        きょうも  いちにち  がんばった   │  ← テキスト入力
│                                    [+ 行追加]  │
└────────────────────────────────────────────────┘
```

**小節形式**:

```
┌────────────────────────────────────────────────┐
│ | C    | G    | Am   | F    |                  │
│ | C    | G    | F    | G    |                  │
│                              [+ 小節を追加]    │
└────────────────────────────────────────────────┘
```

### コード入力・補完

コード入力時にポップオーバーで補完候補を表示。候補はすべて**編集中セクションの有効キー**（セクションに設定があればそれ、無ければ継承値）に基づくため、キーが未設定の場合は候補を表示せず「キーを設定するとコード候補が表示されます」と案内する（手入力でのコード登録は可能）。

```
┌─────────────────────────────┐
│ A                           │ ← 入力中
├─────────────────────────────┤
│ Am     完全一致             │
│ A      前方一致（グレー）    │
│ A7     前方一致（グレー）    │
│ Am7    前方一致（グレー）    │
├─────────────────────────────┤
│ Dm     次コード予測（緑）    │  ← 頻出パターンから予測
│ E      次コード予測（緑）    │
├─────────────────────────────┤
│ F#m7-5 代理コード（オレンジ） │  ← 音楽理論に基づく提案
└─────────────────────────────┘
```

### 自動保存

- 編集後2秒間操作がなければ自動保存
- ステータスバーに保存状態を表示
- Ctrl+S で即座に保存

### キーボードショートカット

| ショートカット | 機能                   |
| -------------- | ---------------------- |
| Ctrl+S         | 保存                   |
| Ctrl+Z         | 元に戻す               |
| Ctrl+Shift+Z   | やり直す               |
| Tab            | 次の入力位置へ移動     |
| Escape         | ポップオーバーを閉じる |

### ステータスバー

```
保存済み | 推定キー: C | コード数: 24
```

```
│  └─────────┴─────────┴─────────┴─────────┘       │
│                                                  │
│  最近編集した曲                                   │
│  [楽曲カード] × 最大5件                           │
│                                                  │
│  アカウント設定            [アカウント設定を開く]  │
│                                                  │
└──────────────────────────────────────────────────┘
```

### 機能

- プロフィールヘッダー（アバター・表示名・メールアドレス・登録日）
- 楽曲サマリー（公開範囲別の件数、`GET /api/me/summary`）
- 最近編集した曲（最大 5 件、`GET /api/me/songs?limit=5`）
- 「アカウント設定を開く」でアカウント設定モーダルを表示

### アカウント設定モーダル

Clerk の `<UserProfile />` は使わず、ChordBook 独自 UI で提供する。

| 項目             | 操作     | 実装                                       |
| ---------------- | -------- | ------------------------------------------ |
| アバター         | 変更・削除 | Clerk `user.setProfileImage()`（10MB まで） |
| 表示名           | 編集     | Clerk `user.update()`                      |
| メールアドレス   | 表示のみ | 連携アカウント由来のため変更不可           |
| 連携アカウント   | 表示のみ | `user.externalAccounts` の一覧             |

- 表示名は姓名を分けず、Clerk の `firstName` に一本化して保存する（`lastName` は空）
- 変更は Clerk に保存され、Clerk Webhook（`user.updated`）経由で `Users` テーブルにも反映される
- サインインは Google OAuth のみのため、パスワード変更は提供しない
- 旧 `/profile/account` は廃止し、`/profile` へリダイレクトする

### 未実装

- アカウント削除（退会）

## 10. 共有楽曲表示画面

**パス**: `/share/:token`
**認証**: 不要（ログインなしで閲覧可能）

### 概要

共有リンク（URL共有）からアクセスした際の閲覧専用画面。ログインしていなくても、有効な共有トークンがあれば楽曲を閲覧できる。譜面の表示は楽曲詳細・エディタプレビューと共通のコンポーネント（`ChordSheet`）を使う。

### 構成要素

```
┌──────────────────────────────────────────────────┐
│ [ChordBook ロゴ]            [ログインして編集]    │
├──────────────────────────────────────────────────┤
│  共有コード譜                [ログインして始める]  │
│                            [▶ 演奏モード]        │
│  [移調 − 0 + ]                                   │
│  ────────────────────────────────────────────    │
│  曲名タイトル                                     │
│  アーティスト名   Key: C   BPM: 120   4/4        │
│  ═══════════════════════════════════════════    │
│                                                  │
│  INTRO                                           │
│  C        G        Am       F                    │
│                                                  │
│  ...                                             │
└──────────────────────────────────────────────────┘
```

印刷時は案内バナー・ボタン・移調コントロールが非表示になり、譜面（`ChordSheet`）だけが出力される。

### 機能

- コード譜の閲覧（読み取り専用）- ログイン不要
- トランスポーズ - ログイン不要
- 印刷 / PDF エクスポート - ログイン不要
- ブックマーク追加（ログイン必要）

### アクセス条件

- 有効な共有トークンがあれば誰でも閲覧可能
- 有効期限が設定されている場合は期限内のみアクセス可能
- 無効なトークンの場合はホーム画面へリダイレクト

## 11. 自分の楽曲一覧画面

**パス**: `/profile/songs`
**認証**: 必要

### 概要

`/songs` が全ユーザーの公開楽曲一覧になったことに伴い、非公開・URL限定公開を含む自分の全曲へアクセスするための画面。プロフィール画面の「最近編集した曲」（直近5件）の「すべての楽曲を見る」リンク先。`GET /api/me/songs`（limit 未指定）で公開範囲に関わらず自分の全曲を取得する。

### 機能

- 楽曲カードの表示（タイトル、アーティスト、キー、更新日、詳細・編集リンク）
- 検索フィルター（クライアント側、タイトル・アーティストの部分一致）
- 新規作成ボタン
